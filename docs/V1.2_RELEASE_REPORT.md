Known limitations (honest): VFX applies a static per-camera matte (temporal tracking stays in Roto Studio);
Colourist does global per-camera matching, not shot-level secondary grading; highlight scoring is heuristic
(energy, turn-taking, overlap, emphatic language when a transcript exists).

* **C++** (unit): 6/6 Bang On Pro CTest suites incl. `bangonpro_test_agent_control_centre`; local Qt5/KF5 build
  and macOS arm64 Qt6/KF6 Craft build.
* **Real application** (real-app, virtualised Xvfb display, synthetic media): the built binary launched;
  Agent Control Centre recovered a job and rendered all 14 agents

  Lift/Gamma/Gain, A1 dialogue and QC markers (`docs/screenshots/v1.2/draft_project_open_in_bang_on_pro.png`).
* **Packaged app** (virtualised Apple Silicon CI): `verify_department_in_bundle.py` runs a full production job
  inside the DMG's bundled runtime with TTS dialogue, installs Whisper tiny + MobileSAM through the Model
  Manager, and fails the release if installed models are not used for neural inference. **Verified** in
  [CI run 45513598081](https://github.com/kierantrestain/Bang-on-pro/actions/runs/45513598081) on a
  virtualised Apple Silicon runner (`kern.hv_vmm_present=1`): faster-whisper ASR neural (transcribed

## 5. Editing-time objective (60–85 %)

Formula implemented exactly as specified:
`(manual baseline − agent-assisted human time) / manual baseline × 100`, with setup, review, corrections and
approval counted, idle gaps excluded (`python -m bangonpro.ai_engine.department measure start|activity|finish|report`).

**Status: NOT MEASURED — the target is not claimed.** No paired sessions by human editors on representative
licensed footage were available (EXT-003, EXT-005). A *modelled* planning estimate for the synthetic job
(operation counts × assumed manual task times) is 1,568 s manual vs 66 s review (95.8 %); it is an assumption,
not evidence. To measure: run one manual and one assisted session per deliverable for podcast, gameshow,
sports discussion and daily news, then `measure report --jobs <job dirs>`.
