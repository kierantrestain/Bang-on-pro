# Bang On Pro V1.5.1: functional integrity audit (internal pre-release)

**Branch:** `claude/fervent-johnson-qumhhc`, built on the V1.5 release `33b9609` (four reasoning providers with failover, persistent department learning).
**Scope:** audit, repair and consolidate what already exists. No new features, agents, models, frameworks or dependencies. One lead engineer; no development agents.

## How it was audited

- Traced both front doors from the native UI to the native timeline: the **AI Assistant** (`ai_engine.cli` → planner → Timeline Command batch → C++ `TimelineCommandEngine`) and the **Agent Control Centre** (`department` jobs → 14 agents → draft `.kdenlive` → staged through the same C++ engine), plus the MCP agent path (`mcp` tools → edit layer → draft, `bop_live` → C++ server).
- Import graph, dead-code scan (vulture, checked by hand against Python, C++, packaging, tests and docs), AST duplicate scan, silent-exception scan, and a scan of every Qt signal declared by the Bang On Pro widgets for a connected receiver.
- Every claim about an edit was checked on rendered output where possible (melt renders, pixel checks), not on command text.

## Dead and duplicate code removed

- Unreferenced functions (checked in Python, C++, packaging, tests and docs): `_score_highlights_v121`, `_dominant_segment_for_window`, `inspect_asr_backend_status`, `is_valid_mlt_audio_filter`, `lipsync_error_at`, `registry.get_agent`, `_compute_sha256_file`, `ModelManager.unload_model`, `plan_project_edit`, `has_mutating_actions`, `frame_to_sec`, and the registry's unused `check_local_availability`, `register`, `configure_from_dict`, `_merge_provider_entry`, `load_from_json_file`.
- Phantom providers (`openai_compatible`, `anthropic`, `deepgram`, `local_ollama`, `local_whisper_cpp`) and the whisper.cpp model entry.
- Unused imports. The duplicate `revise` fallback in the department CLI now uses the single `reasoning_fallback`.
- Product Python: 234 lines added, 468 removed; tracked package 2,244,043 → 2,230,540 bytes.

Kept on purpose: the public data-model methods of the transcript, Roto cache, ArtCraft compositor and proxy cache (public API exercised by tests or the CLI), and all inherited Kdenlive code.

## Components consolidated

- **One reasoning and provider-routing system:** AI Assistant, Agent Control Centre revisions and MCP tasks use `mcp/reasoning.py` (one priority order, failover, budget and ledger). The provider registry now lists exactly those providers.
- **One draft QC on the emitted timeline:** `check_draft` serves MCP tasks, strategy evaluation and every department production.
- **One execution semantics for masks:** the Python draft builder and the native C++ bridge produce the same filters for the same operation.
- **One revise path:** rules → validated skill → shared router, for the UI and the MCP `instruct` command.
- **Learning:** the preference store (human-approved profile versions) and the SQLite intelligence store are layered, not duplicated: corrections recorded in the first are captured as evidence in the second. No change was needed.

## Remaining limitations and genuine blockers

- **Roto mask tracking from the panel is not connected.** Propagation exists in `roto_studio.cli propagate`, but the panel has no frame-sequence source, so the Track buttons are disabled with an explanation rather than left silent.
- **whisper.cpp is not supported.** It was removed from the catalogue instead of being implemented, because it could not be built or verified here.
- The AI provider dialog's endpoint and model fields are not used. Its mode and data-sharing consent now govern the AI Assistant's use of the shared router.
- Learned strategy settings tune agent-requested titles and camera switches (MCP tools). They are not mapped onto production defaults, because the semantics differ (a minimum hold is not a default length).
- Everything V1.5 listed as limited still applies: only Claude Code has been live-tested; the improvements are measured on synthetic footage; the app has not been tested on a physical Mac and is not notarised.
