## 1. Executive Summary

Bang On Pro **V1.7.0** resolves all outstanding P0 and P1 defects from `v1.6.0-beta.1` and completes the native desktop editing, AI production isolation, Effects Library, dedicated Effect Controls, macOS performance/stability, security, and self-contained Apple Silicon (`arm64`) packaging architecture.

### Key Deliverables Completed

1. **P0 — Complete Project & AI Production Isolation (`F01`, `F02`, `F03`, `F04`)**
   - Every Kdenlive project now carries a persistent canonical `bangonpro.project_uuid` stored in `KdenliveDoc`, propagated across `KdenliveTimelineBridge`, `TimelineCommandEngine`, `BangOnProIntegration`, `job.json`, `queue.json`, and `job_history()`.
   - AI productions are stored strictly under `<storage>/projects/<project_uuid>/jobs/<job_id>` with collision-free UUID-suffixed job IDs.
   - Added `ProjectManager::docAboutToClose(KdenliveDoc *)` and full project lifecycle reset (`resetForProject()`) across `AgentControlCentre`, `AiAssistantDock`, `TranscriptEditorWidget`, `RotoStudioDock`, and `TimelineCommandEngine` — clearing active jobs, prompts (`m_briefEdit`), edit options, series/episode overrides, and history whenever switching to another project or starting a new project.
   - Enforced hard cross-project write guards in `openEditedSequence()` and `stageDepartmentDraft()` plus canonical path containment checks so background workers can never mutate a newly switched project.
   - Implemented full production lifecycle controls: **New Production**, **Start**, cooperative **Pause** (`PAUSE` sentinel + `"paused"` state), **Resume** (only for active-project eligible jobs), escalating **Cancel**, **Retry**, and **Discard** (refused while worker holds kernel `flock`).
   - Upgraded checkpoints to unique PID+UUID sibling temp files with `fsync` + atomic `os.replace`, SHA-256 `checkpoint_sha256` integrity verification (`verify_checkpoint_integrity()`), atomic `promote()`/`relink()` with symlink & original-footage protection, and `0o600` lock files.
   - Fixed pre-`job.json` crash recovery so terminating a worker immediately after launch transitions UI state truthfully to `"failed"` instead of hanging in `"running"`.

2. **P0 — Complete AI Cut Experience & 14 Real Specialist Agents (`F05`, `F06`)**
   - Added compact **Media Source**, **Output Format** (`Match sequence`, `16:9`, `9:16`, `1:1`), and **Target Duration** setup controls wired through `JobOptions` into the AI production department.
   - Added live elapsed clock, lightweight stdlib `resource_usage` (RSS/CPU) telemetry, and an honest engine indicator distinguishing **Local Deterministic**, **Local Neural**, and **Subscription AI** execution.
   - Audited and verified all 14 specialist agents (`executive`, `learning`, `media_ingest`, `synchronisation`, `editorial_intelligence`, `multicam_director`, `rough_cut`, `audio_engineer`, `colourist`, `captions`, `graphics`, `vfx`, `quality_control`, `distribution`) with cached analysis reuse, strict budgets, and independent draft QC.

3. **P1 — Unified Professional Effects Library (`F07`)**
   - Built `UnifiedEffectsPanel` mounted in the persistent **Effects** dock: single searchable, categorized library spanning `All`, `Video`, `Audio`, `Transitions`, `Presets`, `Favourites`, and `Recent` (332 verified native effects, transitions, and Premiere presets in Linux verification).
   - Hides legacy, deprecated, and unverified/unsupported effects by default (opt-in toggle preserved).
   - Fixed Premiere preset drag-and-drop by emitting native `kdenlive/effect` and `kdenlive/composition` MIME payloads, fixed single-effect preset XML ID registration (`resolveInstalledEffectIdFromXml`), and added debounced search + cached preview pixmaps.

4. **P1 — Dedicated Effect Controls Panel & Intrinsic Transform (`F08`, `F09`)**
   - Renamed the stack dock to **`Effect Controls`** and promoted it in both **Edit** and **Effects** workspaces, auto-revealing it whenever an effect is applied or dropped onto a clip (`effectAppliedToClip` / `effectDroppedOnStack`).
   - Built `IntrinsicTransformWidget` pinned at the top of `AssetPanel`: lazy-materialized **Motion / Transform** card (Position X/Y, Scale with aspect lock, Rotation, Anchor Point with exact pivot-compensation math persisted via `kdenlive:anchor_x`/`anchor_y`, Opacity, Blend Mode, Keyframe creation/navigation, Reset, and Enable) backed by native MLT `qtblend` so preview and offline `melt` export match identically.
   - Added one-click **Reset** and **Duplicate** (undo-backed) buttons on every effect header, fixed `EffectStackView::slotSaveStack()` off-by-one bug, added selective **`PasteAttributesDialog`** (`Ctrl+Alt+V`), crisp `#FF5A1F` drop-target highlight + `"+ Drop Effect"` pill in `Clip.qml`, and Premiere-familiar shortcuts (`Shift+5` Effect Controls, `Shift+7` Effects).

5. **P0 — macOS Performance, Stability, Security & Self-Contained Packaging (`F10`, `F11`, `F12`)**
   - **Startup & Idle**: Lazy construction of hidden Bang On Pro docks, single full-app theme apply, zero idle startup Python spawns, signal-driven project context updates, mtime/size-gated queue polling paused when dock is hidden, and non-modal first-launch `SystemCheckDialog`.
   - **Shutdown & Memory**: Parallel `<=1.2 s` subprocess shutdown, fixed `qstrdup()` heap leak in `AudioLevelsTask`, RAM-scaled `audioThumbCache` (16–32 MB), RAM-tier `TaskManager` concurrency caps, 50-entry roto undo cap + 80 ms slider debounce, async `slotCheckCacheSize()`, and PID-checked `0600` `kdenlivelock` with timestamped `.bak` config backups.
   - **Hardware Video & Caching**: Fixed VideoToolbox proxy profiles (`x264-videotoolbox`, `h264-videotoolbox`) and added `prores_videotoolbox` with `prores_ks` fallback; added `fcntl.flock` manifest locking, corrupt backup, and throttled eviction in `proxy_cache_manager.py`; atomic `QSaveFile` autosave in `KdenliveDoc::slotAutoSave()`.
   - **Security & Isolation**: Replaced non-atomic C++ writes with `QSaveFile` across `src/bangonpro/`, enforced `PYTHONNOUSERSITE=1`, `-s`, and stripped host `PYTHONPATH`/`DYLD_LIBRARY_PATH` in all Python invocations, bounded `TimelineCommandServer` to 8 concurrent clients with 60 s idle timeout and `0600` socket perms.
   - **macOS arm64 DMG Packaging**: Unified `1.7.0` version across all manifests, C++, Python, and tests; added Mach-O relocation and external-path leak auditing for `Contents/Resources/python-env`; added aggregate `bangonpro_all_tests` CMake target and expanded macOS CI pytest coverage to 17 suites + `verify_department_in_bundle.py` + sustained benchmark.

## 3. Migration Guidance (V1.2–V1.6 -> V1.7.0)

- **Existing `.kdenlive` Projects**: Projects created in V1.2–V1.6 without a `bangonpro.project_uuid` document property are automatically assigned a deterministic canonical UUID upon first open in V1.7.0 and persisted when saved. Original media footage is never modified or moved.
- **Historical AI Production Directories**: Pre-V1.7 jobs stored under the legacy global `<storage>/jobs/` directory remain intact on disk for manual inspection, while all V1.7+ productions are created under `<storage>/projects/<project_uuid>/jobs/` so unrelated projects never leak state across one another.
- **Corrupted Queue / Cache Files**: If `queue.json` or proxy cache manifests are damaged, V1.7.0 preserves the corrupt file alongside a timestamped `.corrupt.<ts>` backup instead of silently discarding user state.
- **Crash Lock Recovery**: Stale `kdenlivelock` files left behind by dead processes are detected via PID liveness instead of prompting an unnecessary configuration wipe; intentional config resets now preserve timestamped `.bak` backups.

## 4. Known Limitations & Environmental Scope

1. **Physical Bare-Metal Apple Silicon Interactive Testing**: Native Apple Silicon compilation, DMG packaging, Mach-O relocation/leak auditing, clean-environment DMG install/launch, 17 bundled Python test suites, department E2E verification, and `--sustained` benchmarks execute on GitHub-hosted `macos-15` (`arm64`) virtual machines. Interactive bare-metal macOS GUI playback/scrubbing (ProMotion display, physical audio output, real VideoToolbox silicon decode/encode under interactive mouse drag) cannot be executed from this remote environment and should be spot-checked on a physical Mac after downloading the DMG.
2. **Code Signing & Notarization**: If Apple Developer ID (`MACOS_SIGNING_CERT_P12` / `APPLE_ID` / `APPLE_NOTARY_PASSWORD`) repository secrets are not configured in GitHub Actions, the release DMG is ad-hoc signed (explicitly reported in `SIGNING_STATUS.txt`); macOS Gatekeeper will require right-click -> Open or `xattr -dr com.apple.quarantine` on first launch.
3. **Live Cloud Subscription AI Providers**: All local deterministic, neural-contract, and mock-provider tests are verified offline; live authenticated Claude/Codex/Gemini CLI calls require user-signed-in provider CLIs on the end-user workstation.
