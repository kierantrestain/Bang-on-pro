## How to run the real-app acceptance runner (Linux)
Build as CI (`cmake -B build -G Ninja -DQT_MAJOR_VERSION=5 -DBUILD_TESTING=ON && ninja -C build kdenlive`). Run on Xvfb
inside `dbus-run-session` with a short `XDG_RUNTIME_DIR` (Unix-socket limit), own `TMPDIR` (Kdenlive's crash lock) and
`KDE_DEBUG=1`; set `BANGONPRO_AUTOTEST=<script.json>` (steps documented in `src/bangonpro/BangOnProAutotest.h`).
Results: `<script>.result.json`. Fixture footage: `tests/bangonpro/talking_head.py`.
