## 1. Completed Scope

### Reliability & Same-Project Production Ownership (Preserved & Completed)
- Kernel-backed `flock` worker ownership (`<job>/worker.lock`), truthful terminal states (`failed`, `blocked_missing_media`, `interrupted`, `cancelled`), dead-worker reconciliation, `JobBusyError` duplicate-process refusal, escalating cancellation (`CANCEL` → `SIGTERM` → `SIGKILL`), and capped queue auto-resume.
- Simplified **Production** panel with 8 real measured stages (`department/stages.py`), hidden-by-default QC timeline markers with toggle, automatic single-camera YouTube profile (`youtube_talking_head`), truthful brief clause coverage (`department/brief_coverage.py`), and preserved 4-provider subscription router & failover.
- **Second Edited-Sequence Failure Fixed (`requestClipInsertion failed for A4 on track 37 at frame 0`):**
  - *Root cause:* `TimelineModel::requestClipInsertion` read `m_binAudioTargets` (a UI cache reflecting whichever clip was last selected in the Bin). After opening the first edited sequence (which created a title clip and switched sequence), `m_binAudioTargets` was empty/stale for clip `4`, causing audio-only insertion (`A4`) to fail even onto an empty audio track.
  - *Fix:* `TimelineModel::requestClipInsertion` now falls back to `master->activeStreams()` (or `audio_index` if `hasAudio()`) whenever `m_binAudioTargets` is empty or does not match the inserted clip.
  - *Additional bridge improvements:* `KdenliveTimelineBridge::handlePlaceClip` waits for freshly imported bin clip readiness, passes exact inclusive `/in/out` trim bounds directly to `requestClipInsertion` (eliminating 1-frame off-by-one gaps and untrimmed-clip collisions), and `resolveTrackId` resolves `A1`/`A2` by exact Kdenlive tag / top-down audio order so dialogue lands on `A1` alongside picture on `V1`.
- **High-Pass Filter Parameter Mismatch Fixed:** `audio_graphics_qc.py` now emits native Kdenlive `av.f` (matching `data/effects/avfilter/avfilter_highpass.xml`) instead of `av.frequency`, and `KdenliveTimelineBridge::handleAddEffect` normalises legacy `av.frequency` → `av.f` for backward compatibility.

### Reference-Video Style Learning
- Added `bangonpro/ai_engine/department/reference_style.py` and CLI subcommands `department style analyze|list|show|save|delete`.
- Analyses one or multiple reference videos locally using FFmpeg/FFprobe (`ebur128`, `silencedetect`, bounded frame sampling), PySceneDetect (`ContentDetector`), and `media_visual` across all 9 dimensions: shot duration/pacing, cut frequency/transitions, opening structure, camera framing/zooms, caption detection/position, graphics placement/accent colour, colour look (luma/contrast/saturation/warmth), audio loudness/pauses, and B-roll cutaway share.
- Caches per-video observations by SHA-256 content hash in `AnalysisCache` (`namespace="reference_style"`).
- Uses authorised subscription reasoning selectively for semantic summaries via the shared `CliReasoner` router when connected and enabled; otherwise operates 100% locally and reports `reasoning.used = false`.
- Converts observations into editable, schema-validated Show Profiles (`show_profile_v1.schema.json`) stored in `default_custom_profiles_dir()`, with Colourist support (`media_colour.py` + `media_intel.py`) so learned styles produce measurable timeline, audio, and rendered pixel differences on different source footage.
- Wired the Production panel's **Reference videos…** button (`BangOnProIntegration::openReferenceStyles`) and menu action to the new native `ReferenceStyleDialog` (import videos, analyse, preview observations, adjust parameters, approve & save, select, and delete styles).

### Intelligent Motion Graphics (Existing Graphics Agent Extended)

  - Validates title-safe (90%), action-safe (93%), WCAG contrast (≥ 4.5:1), non-overlapping V2 time allocation, and caption-band collision avoidance.
